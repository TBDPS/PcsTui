`pcstui` 的能力均为原生 Rust 实现（除 Yazi/`xdg-open` 外部程序）。BaiduPCS-Go 列用于说明协议能力边界，不代表本项目需要逐项对齐。

## 7. pcstui 的关键能力

1. **原生协议层**：直接调用百度 HTTP API，错误保留 `errno`/`request_id`。
2. **双栏 TUI**：本地与远程同屏，下载/上传方向明确。
3. **结构化传输任务**：任务 id、方向、源/目标、字节进度、速度、状态、取消。
4. **下载断点**：`.part` + HTTP Range；服务端不支持 Range 时自动重来。
5. **下载 MD5**：完成后校验；目录 MD5 是 block-list MD5 时改用下载主机 `Content-MD5`。
6. **上传断点**：持久化 `uploadid` 与分片完成状态，跨进程恢复。
7. **上传校验**：整文件 MD5、slice-MD5、CRC32、分块 MD5 单遍计算；合并后再次读取服务端内容 MD5。
8. **可移植凭据**：配置导出/导入、TUI 登录页、凭据掩码，源码与可执行文件不含账号信息。
9. **权限自检**：配置/状态目录启动时收紧。
10. **窄屏布局**：<100 列自动上下分栏。
11. **Yazi 生命周期管理**：挂起/恢复终端，退出后刷新。
12. **脚本化 CLI**：`--json`、`--quiet`、`--yes`、`doctor`。
13. **多连接下载**：≥64 MiB 文件按 4 MiB Range 并行，分片位图支持跨进程恢复。
14. **全局并发限制**：下载/上传分别限流，避免批量操作打满连接。
15. **持久化待办队列**：`config/queue.json` 记录未完成任务，TUI 重启后自动恢复。
16. **序号导航与元数据**：`1`–`99` 跳转可见项；底部显示路径、大小、时间、`fs_id`、MD5。
17. **输入框自由编辑**：重命名/跳转/移动等输入支持光标移动与常用编辑键。

## 8. 已知差距

| 差距 | 影响 | 建议 |
| --- | --- | --- |
| 行尾实时预览 | 中文长文件名下选错概率低 | 已有底部元数据行；可再加选中行详情浮层 |
| 本地过滤保持原序号 | 过滤后仍可按原列表序号操作 | 当前序号按可见行计算；若需要原索引需另存映射 |
| 搜索接管列表并支持跳父目录 | 搜索后操作流畅 | TUI 已支持搜索；可加“跳转到所在目录” |
| 完整 MD5/路径详情 | 排障方便 | 增加 `pcstui info` 或 TUI 详情浮层 |
| 下载后一键 Yazi 定位 | 下载后立即处理 | 记录最后完成任务，`y` 时定位 |
| 透传任意 `pcs` 命令 | 高级功能不受限 | 不追求；按需实现分享/离线/回收站 |

## 9. 与 BaiduPCS-Go 的差距

| 差距 | 优先级 | 说明 |
| --- | --- | --- |
| 分享/转存 | P2 | 独立 API 与风控，建议单独模块 |
| 离线下载 | P2 | 任务轮询、配额、资源策略 |
| 回收站 | P2 | 列表/恢复/彻底删除 |
| 多账号 | P2 | 配置模型迁移 |
| 单文件分片并发上传 | P1 | 状态文件需支持多 worker 原子更新 |
| 队列暂停/重排/优先级 | P1 | 当前只支持恢复与取消 |
| 限速 | P2 | 令牌桶 |
| 密码/验证码登录 | P3 | 不建议 |
| `tree`/`meta`/`sumfile` | P2 | 易加，但非主路径 |
| 跨平台打包 | P2 | Windows 终端与路径测试 |

## 10. 建议路线

### P0（稳定性）

- 破坏性操作前用 `fs_id` + mtime 复核目标；
- 上传中断/恢复的端到端自动化测试；
- TUI 快照测试与窄屏回归；
- 多连接下载在弱网/限流账号下的故障注入测试。

### P1（传输体验）

- 单文件分片并发上传（保持状态文件线程安全）；
- 队列暂停/重排/失败重试 UI；
- 限速；
- 上传前哈希结果的持久化缓存，避免超大文件恢复时重算。

### P2（能力补齐）

- `info`/`tree`/`sumfile`；
- 分享/转存；
- 离线下载；
- 回收站；
- 多账号；
- 主题与鼠标。

### P3（不建议）

- 密码/验证码登录；
- 加密直链签名破解；
- 旧式 `rtype=3` 秒传。

## 11. 一句话总结

- **BaiduPCS-Go**：功能最全、协议最成熟，但偏 CLI，缺少现代双栏 TUI。
- **pcstui**：在“原生协议 + 双栏 TUI + 可恢复传输 + 可移植配置”上取交集，功能覆盖小于前者，但关键路径更可控、更可测试。
