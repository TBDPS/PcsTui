# 功能矩阵：TUI / CLI

pcstui 是 TUI 优先的百度网盘客户端。CLI 保留为脚本与冒烟测试入口，不追求与 TUI 功能对等，也不承载配置面板、诊断浮层、重新登录等交互能力。

- ✅ 完整可用
- 🟡 部分可用
- ❌ 未实现
- — 不适用

## 7. 关键能力

1. 原生协议层：直接调用百度 HTTP API，错误保留 `errno`/`request_id`。
2. 双栏 TUI：本地与远程同屏，下载/上传方向明确。
3. 破坏性操作按 `fs_id` 复核：项目已变化时整批中止。
4. 结构化传输任务：方向、源/目标、字节进度、速度、状态、取消。
5. 下载断点：`.part` + 分片指纹；缺失/截断/损坏时拒绝拼接。
6. 上传断点：持久化 `uploadid`、分片完成状态与本地整文件 MD5。
7. 持久化待办队列：按任务身份去重，重启后恢复。
8. 可移植凭据：TUI 内导出/导入、在线验证、备份替换、掩码显示。
9. 权限自检：配置/状态目录启动时收紧。
10. 脚本化 CLI：`--json`、`--quiet`、`--yes`、`doctor`。

## 8. 已知差距与路线

### P0（稳定性）

- TUI 快照测试与窄屏回归；
- 上传中断/恢复的端到端自动化测试；
- 多连接下载在弱网/限流账号下的故障注入测试；
- 慢网超时拆分（当前请求仍为 120s 总超时）。

### P1（传输体验）

- 单文件分片并发上传（状态文件需支持多 worker 原子更新）；
- 队列暂停/重排/失败重试 UI；
- 限速；
- 上传前哈希结果持久化，避免超大文件恢复时重算。

### P2（能力补齐）

- `info` / `tree` / `sumfile`；
- 分享/转存、离线下载、回收站；
- 多账号；
- 主题与鼠标；
- 跨平台终端与路径测试。

### P3（不建议）

- 密码/验证码登录；
- 加密直链签名破解；
- 旧式 `rtype=3` 秒传。
